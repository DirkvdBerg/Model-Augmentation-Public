The following grey-box approaches appear in practice: parameter re-estimation within the physics model structure, static residual correction on the model output, and dynamic augmentation that extends the baseline with learned states \cite{willard2020integrating, noel2018greybox}.
For the dual-gantry system, the first-principles baseline does not fully capture cross-coupling between axes or position-dependent flexible dynamics, even with re-fitted parameters; both require additional model states, which static correction and re-estimation are unable to provide \cite{hoekstra2026lfr}.
Dynamic augmentation is therefore the right approach, because it extends the first-principles baseline with learned states that can capture dynamics the physics-based model cannot describe \cite{hoekstra2026lfr}.
\\
Since the payload position ($Y$) of the physical baseline model enters the inertia matrix algebraically \cite{garcia2013model}, the system exhibits structural position dependence. This means the physical baseline can be formulated directly in LPV form, with $Y$ as the scheduling variable. When the scheduling variable is not available from the physical model, it must instead be identified from data \cite{verhoek2022deeplpv}. In this case $Y$ follows directly from the first-principles model and does not require data-driven identification.
\\
The linear fractional representation (LFR) \cite{hoekstra2026lfr} provides a unified framework for augmentation architectures, in which the first-principles baseline and the learned component are connected through a structured interconnection. In addition, MIMO nonlinear systems can be systematically represented in LPV-LFR form \cite{schoukenstoth2018mimo}. 
Especially during joint estimation, if the physical baseline and the learned component share the same output space, the augmentation can start to capture dynamics that are already described by the baseline. This effect is known as negation \cite{kon2022physics, gyorok2025l4dc, kessels2025ai}. Regularization of the parameter values can help preserve interpretability when identifiability is limited \cite{hotvedt2021identifiability}, but it does not structurally prevent negation. A parallel structure is chosen, because orthogonal projection-based regularization is formulated specifically for parallel structures and is not readily applicable to a series interconnection \cite{gyorok2025l4dc}. Orthogonal projection constrains the augmentation output to the subspace orthogonal to the baseline output, thereby helping to keep the physical parameters meaningful \cite{kon2022physics, gyorok2025l4dc}.
The LPV-LFR model is learned by gradient-based methods, with well-posed parameterizations ensuring a consistent estimation problem \cite{hoekstra2026lfr, drenth2025lpvlfr}. Augmented models also introduce hidden states that cannot be measured directly, requiring an initialization strategy for simulation \cite{hoekstra2026encoder}.
\\
Free-run simulation is used for validation, since simulation accuracy is the relevant criterion for settling prediction \cite{champneys2024baseline}. The primary fit measure is the Best Fit Rate (BFR) \cite{toth2010modeling, drenth2025lpvlfr}.
Generalisation is evaluated in two ways: at held-out operating points that are representative of actual industrial operating conditions, which directly tests the interpolation assumption underlying LPV models built from local operating-point data \cite{paijmans2008identification, bachnas2014review}, and on unseen motion profiles that are relevant to the industrial use context \cite{champneys2024baseline}.
