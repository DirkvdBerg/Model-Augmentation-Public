  Common power between signals                                                  21/60


  So the product of the Fourier series U (f ) and U ∗ (f ) of a single signal
  u(t ) returns the energy within a single signal per frequency.

                                       Suu (f ) = U (f )U ∗ (f )

  Then the product of the Fourier series of different signals u(t ) and v(t )
  returns their common power per frequency.

                                       Suv (f ) = U (f )V ∗ (f )


      I   Known as Cross Power Spectral Density (CPSD)
      I   can indicate ‘common power’ between the signals
      I   signals could be related if this common power repeats

  Cross Power Spectral Density (CPSD):

                                       Suv (f ) = U (f )V ∗ (f )

  Interpretation:
      I   For each frequency: how much power of u is present in v?
      I   Can indicate (cross-)covariance between u and v
  Remarks:
    I S
       uv (f ) does contain phase information
               •   Indicates how much v is shifted w.r.t. u for each frequency f
      I               ∗ (f )
          Svu (f ) = Suv
               •   same magnitude, negative phase
      I   If u = v, then Cross PSD reduces to Auto PSD
      I   Matlab: cpsd.m (again, be aware of scaling!)
