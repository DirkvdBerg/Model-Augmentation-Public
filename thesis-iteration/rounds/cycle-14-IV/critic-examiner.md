So "no update of theta_aug moves the corrected write into ran Phi" holds whether the coefficient is differentiated through or detached, since a coefficient re-solved on every forward pass is orthogonal either way.    rule_cause: skill "Justify only what an examiner would question" (the reason must name what the alternative loses) was not applied; README "Prose around the math" (at most one consequence; a choice that fixes an element of a display is argued in its lead-in) was not applied to the differentiated/detached choice.
