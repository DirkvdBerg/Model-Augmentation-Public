# Q-012 Y-scheduled LPV augmentation (discussion, Toth)
**Position.** The baseline is self-scheduled LPV: Y is both a state and the scheduling variable (E-070). The network receives the six baseline states, Y included, plus the added states and the forces (E-049), so its correction already depends on Y, but implicitly.
**Mechanism.** Explicit scheduling would make the learned block a function of Y with learned Y-independent coefficients, so the augmented model is LPV by construction and frozen-Y analysis applies.
**What else was possible.** A learned block with an explicit LPV or LPV-LFR structure instead of an MLP.
**My view (opinion).** Explicit scheduling helps analysis (frozen-Y stability, interpolation between positions) more than accuracy. The absorber is not strongly Y-dependent, so I expect little accuracy gain here.
**30 s.** "The network sees Y, so the correction is position dependent, but without an explicit LPV structure. Explicit scheduling would make frozen-Y analysis possible; for this absorber I expect little accuracy gain."
