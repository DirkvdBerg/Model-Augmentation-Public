# Q-019 Using the real controller code and machine data (discussion, Gerritsen)
**Position.** The results are simulation only, with the same controller that generated the data (E-055); measured data and a different controller are future work (E-069).
**Mechanism.** The model force is the recorded force plus the controller acting on recorded minus model output (E-041), which needs only the recorded force and position (E-042). On the machine that means the implemented controller as a known block, and synchronised force and position logs.
**What else was possible.** Kessels reconstructs the controller state from the measured output, the reference and the known controller (E-012).
**My view (opinion).** Needed from ASMPT: the discrete controller as implemented (rate, filters, delays), synchronised actuator-force and encoder logs, and identification records with multisine.
**Practice gaps (2026-10-30).** Answer drifted to "change the controller, fix the parameters". Keep the controller as the machine's own known block; nothing is fixed beforehand, beta is estimated. Also say: the noise floor is defined with the noise-free output (E-058), which does not exist on real data, so the criterion must be redefined (my derivation, opinion).
