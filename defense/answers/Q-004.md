# Q-004 Plant model versus closed loop (discussion, Shakib)
**Position.** Check the plant in open loop, not only the closed-loop error.
**Mechanism.** The thesis compares open-loop Bode magnitudes from F_Y to Y of the linearised models with the system (E-006). The controller has a 100 Hz bandwidth (E-007); the absorber mode sits above it, where the loop barely suppresses plant error, so the closed-loop error there does test the plant. Below the bandwidth the controller suppresses plant error, which is where the rigid-body parameters act.
**Evidence.** E-006, E-007, E-005.
**Limit.** One controller only (E-005); a changed controller with another bandwidth is not tested.
**My view and next step (opinion).** Simulate the trained model and the truth with a second controller; in simulation that is cheap.
**30 s.** "I look at the open-loop FRF of the trained model against the system, without the controller. Above the 100 Hz bandwidth the closed-loop error tests the plant directly; below it the controller hides plant error, and I have tested only one controller."
