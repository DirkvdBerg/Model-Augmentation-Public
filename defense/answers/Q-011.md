# Q-011 Closed-loop validation and the criterion stated beforehand (discussion, Schoukens)
**Position.** The criterion in the thesis is the noise floor: the NRMS_e with the model output replaced by the noise-free output (E-058). The final model stays far above it on every record (E-059), so by this criterion it is not yet satisfactory.
**Mechanism.** In closed loop the recorded input is correlated with the noise through the feedback (E-053), so consistency is not shown (E-054), and the controller can suppress plant-model errors (E-056). A small closed-loop error is necessary, not sufficient, for a good plant model.
**What else was possible.** Evaluation on measured data and with a different controller, named as future work (E-069). The thesis also compares open-loop plant FRFs of the models with the system (E-006).
**My view (opinion).** The strongest validation is controller transfer: predict the loop with a controller the model was not trained with. Residual whiteness and input-residual correlation tests are cheap additions.
**30 s.** "The criterion is the noise floor, and the model does not reach it. Because feedback can hide plant errors, the next validation is a different controller."
**If pushed.** "The criterion is data-derived, but it judges the closed-loop output; it does not certify the open-loop plant. That is stated as a limitation (E-055, E-056)."
