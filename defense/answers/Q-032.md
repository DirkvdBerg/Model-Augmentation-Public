# Q-032 Normalisation (explain, Toth)
**Equations.** x^n = T_x (x - mu_x). Baseline: f_base^n = T_x (f_base - mu_x) (E-144). Correction scaled only by T_x, since f_base^n already subtracts mu_x (E-136). Output map C^n = T_y P^T [I 0] T_x^-1, linear (E-143), because position means are set to P^-T mu_y so mu_y cancels (E-145).
**Mechanism (say it).** The next state is absolute, so its mean is removed once, in the baseline term. The network adds an increment, so it is only scaled. Subtracting mu_x again would remove the mean twice and the network would have to learn an offset to undo it.
**Output.** y = P^T q; with mean P^T P^-T mu_y = mu_y the offset cancels.
**30 s.** "States and outputs are shifted and scaled. The baseline predicts an absolute next state, so it is shifted; the network adds a correction, so it is only scaled. Position means are P^-T mu_y, so the output map has no offset."
