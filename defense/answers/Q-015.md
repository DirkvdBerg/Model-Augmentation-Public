# Q-015 Parallel versus series or feedback LFR augmentation (discussion, Hoekstra)
**Position.** Dynamic parallel was chosen because orthogonality by construction is defined for the additive structure (E-044), and because the missing dynamics need added states (E-045).
**Mechanism.** The correction is added to the baseline state update, so the baseline step stays intact and its parameter directions are defined for the projection.
**What else was possible.** Hoekstra et al. list parallel and series interconnections (E-072) and note that different interconnections may give an equally accurate model, while complexity and convergence speed also count (E-082).
**My view (opinion).** The absorber is a mass driven by the payload that pushes back: physically a feedback interconnection. A feedback LFR structure would match it better, but OBC would have to be rederived for it.
**30 s.** "Parallel, because OBC is defined for the additive structure. A feedback structure would match the absorber physics better and is the next structure to test, but the projection must then be extended."
**If pushed.** "I did not compare structures numerically, so the accuracy difference is open."
