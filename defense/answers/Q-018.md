# Q-018 Online re-estimation for health monitoring (discussion, Gerritsen)
**Position.** Not yet: the estimates depend on the start and cannot be used to trace a machine change to a physical parameter (E-060, E-061), so tracking them online would not mean anything yet.
**Mechanism.** Monitoring needs a change in an estimate to mean a change in the machine, which needs start-independent estimates first.
**What else was possible.** Györök, Péni, Schoukens and Tóth give batch-wise and recursive online learning for encoder-based neural state-space models (E-079), the same model family.
**My view (opinion).** First remove the start dependence, then a recursive update of only the ten combinations with the network frozen.
**30 s.** "Online learning for this model class exists, but my estimates still depend on the start, so a drift would not yet mean a machine change. That comes first."
**If pushed.** "Data and compute per update are not measured in the thesis."
