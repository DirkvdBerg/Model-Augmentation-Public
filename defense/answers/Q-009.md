# Q-009 One training window end to end (explain, Hoekstra)
**Order to say it.**
1. Encoder: from past inputs and outputs before tau it estimates the full initial state, physical and added (added states are latent, E-038). Its physical rows start from a least-squares fit to baseline-simulated states (E-043), then it is trained jointly.
2. Rollout, per sample k: output y_hat from the physical state; controller K_fb acts on y_k - y_hat_k (recorded minus model output), x^c_tau = 0; model force = recorded force plus that correction (E-041, E-042; code `closed_loop.py:92-104`, MATCH OK); state update with baseline plus network.
3. Loss: weighted normalised output error over the window.
4. Gradient: the controller is fixed (not trained) but differentiable, so the gradient flows through it into earlier network outputs. Trained: beta (baseline parameters), network, encoder.
**Common errors in the practice answer.** The correction is not "with respect to the reference": it is driven by y - y_hat, which needs only recorded force and position (E-042). Do not mix in PS (that initialises the added-state weights before training, a separate step).
**30 s.** "The encoder maps past inputs and outputs to the full state at tau. Each sample, the model outputs a position, the fixed controller acts on measured minus model position, and that correction is added to the recorded force before the state update. The loss is the normalised output error over the window; gradients flow through the controller but only beta, network and encoder are trained."
