# Q-025 Choosing the number of added states (considered, Schoukens)
**Claim.** Number of added states and PS were chosen by comparing the simulation error of M_U per combination (E-121), from the true parameters so parameter errors do not affect the choice (E-122). Without added states or without PS the Y error with multisine stays above 50 % (E-123); two with PS reach 6.1 % (E-102); eight give similar errors (E-103).
**Mechanism.** Grid over n_xbar in {0, 2, 8}, with and without PS; pick the smallest that reaches the error plateau.
**What else was possible.** Truth-free order selection: count resonances in the FRF of the residual; smallest order on the validation-error plateau; inspect the learned poles (final model: one mode at 212 Hz, E-127).
**My view (opinion).** The grid brackets the known truth (two states = one mode), which is fine in simulation, but on a machine I would choose the smallest order where validation error stops improving, and check that the learned poles are physical. Eight giving the same error says the extra states add nothing: they are redundant, not harmful.
**30 s.** "A hyperparameter search on simulation error: 0, 2, 8 added states, with and without PS. Two with PS gave 6.1 %, eight the same, so I take the smallest. Without the truth I would take the smallest order on the validation plateau and check its learned poles."
**If pushed.** "Yes, 2 is the true order, so the grid was easy. A finer grid (1, 3, 4) would show whether the plateau starts exactly at 2."
