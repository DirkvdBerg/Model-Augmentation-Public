# Q-020 Transfer to another gantry of the same type (discussion, Gerritsen)
**Position.** Not tested: the thesis uses one simulated system. No local paper on transfer between machines.
**Mechanism (said out loud, opinion).** The baseline structure is shared by the type; the physical parameters are machine-specific; the network holds what is missing, which may be partly type-specific (a mode) and partly machine-specific (friction).
**My view (opinion).** Reuse structure and network as a start, re-estimate the ten combinations, and fine-tune the network on a short identification record of the new machine.
**30 s.** "Not tested. I would reuse structure and network as a start and re-estimate the physical combinations on the new machine."
