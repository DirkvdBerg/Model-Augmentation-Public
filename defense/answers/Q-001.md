# Q-001 Contribution despite non-interpretable parameters (claim, Schoukens)
**Claim.** Prediction yes, interpretability no, and the thesis says so (E-001, E-005).
**Mechanism.** A parallel augmentation with PS-initialised added states, trained in closed loop, captures the missing dynamics and generalises to held-out positions and profiles, better than the black box on average (E-039). OBC lowers the network's overlap with the parameter directions: 0.00 on training records, 0.24 on interpolation test records (E-040). The missing dynamics themselves overlap 0.59 with those directions (E-040), so the estimate is pulled away from the truth (E-002).
**Evidence.** E-001, E-002, E-005, E-039, E-040.
**Careful.** Overlap is measured against the one-step parameter directions (columns of the regressor), not against the baseline output, and it is not a negation measure. Negation is not measured in the thesis. Do not say "it succeeded at negation".
**What else was possible.** Selecting the run with the best parameter error needs the true values (oracle).
**My view (opinion).** The negative result is informative: it identifies non-orthogonal missing dynamics as the reason, which a successor must handle (e.g. constrain the augmentation structurally, or excite so the directions separate).
**30 s.** "The model predicts better and generalises, beating the black box on average. OBC keeps the network out of the parameter directions on the training data. But the missing dynamics themselves overlap 0.59 with those directions, so the parameters still absorb part of them: interpretability as I defined it is not reached, and the thesis states why."
**If pushed.** Uniqueness holds only for the first-order one-step approximation; multi-step closed-loop windows and added states are not covered.
