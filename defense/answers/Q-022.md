# Q-022 Classical model updating instead of augmentation (discussion, Shakib)
**Position.** Refitting only the physical parameters lets them absorb unmodelled dynamics (E-046), and the missing mode needs states the baseline does not have (E-045, E-068).
**Mechanism.** Augmentation estimates the parameters jointly with a learned block; OBC keeps the block out of the parameter directions.
**What else was possible.** Kessels names as future work tuning the physical parameters inside the optimisation, possibly with regularisation, and enforcing orthogonality (E-081); the thesis does both. Adding the absorber as physics is the obvious alternative when the mode is known. No local FE model-updating paper.
**My view (opinion).** When the missing physics is known, model it. Augmentation targets what is not known; the simulation used a known mode to have a ground truth for evaluation.
**30 s.** "Pure updating lets the parameters absorb the missing dynamics. If the mode is known, adding it physically is better; augmentation targets dynamics that are not known."
**If pushed.** "The known truth is what makes the evaluation possible; it is a design choice, not a claim that a network is needed for this mode."
