# Q-023 Gaussian-process or Koopman models (discussion, Schoukens)
**Position.** The thesis mentions GP-based methods only as physics-informed approaches (E-047). Neither class was tried.
**Mechanism.** Koopman eigenfunctions give coordinates that globally linearise the dynamics (E-078). No local paper opened on GP state-space models, so keep claims on how a GP model works out.
**My view (opinion).** Koopman: a linear lifted model can hold the absorber, but the physical parameters would no longer be a block. GP: attractive for the uncertainty question (Q-014), but costly on long 4 kHz records.
**30 s.** "Not tried. Koopman models linearise in lifted coordinates, which loses the physical parameters as a block. A GP correction would give uncertainty, at a high data cost."
