# Q-016 Encoder changes in hindsight (discussion, Hoekstra)
**Position.** The encoder estimates all states, the measured positions included, to keep positions consistent with the estimated velocities (E-050, E-051). The added states turned out to need PS: without it the mode is not found (E-071).
**Mechanism.** The added states are not measured, so each window needs their initial value from the encoder (E-038); PS trains that part to give a predictive state.
**What else was possible.** Positions from the measurement, encoder only for velocities and added states.
**My view (opinion).** Keep the full-state estimate for consistency, but simplify the added-state initialisation into one stage instead of two-stage PS.
**30 s.** "In hindsight the added-state part of the encoder matters most: without PS the mode is not found. I would simplify that initialisation, not the physical part."
**If pushed.** "No run takes positions from the measurement, so that effect is untested."
