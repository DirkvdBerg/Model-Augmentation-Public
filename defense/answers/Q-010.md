# Q-010 PNLSS or Volterra instead of a neural augmentation (discussion, Schoukens)
**Position.** The model class follows from the missing dynamics: the absorber is a vibration mode the baseline cannot represent with its states (E-068), so the augmentation needs added states, which parameter re-estimation and static output correction cannot provide (E-045). Which function fills the learned block is a second choice.
**Mechanism.** The parallel structure keeps the physics block and adds a learned state update with inputs: baseline states, added states and actuator forces (E-049). An MLP or a polynomial in that place leaves the structure and OBC unchanged; the structure is chosen for OBC (E-044).
**What else was possible.** Noël et al. identified a grey-box model with a third-degree multivariate polynomial in the state equation, 37 parameters (E-073, E-074). Volterra: no local paper, keep any claim about it out.
**My view (opinion).** A polynomial block suits a smooth single mode, but the friction is close to a sign function, which needs high order and risks blow-up in free run; a tanh MLP saturates. Next step: the same data with a low-order polynomial block.
**30 s.** "The missing absorber needs added states, so the choice is a dynamic augmentation. The learned block could be polynomial, as in Noël's grey-box example; I followed Hoekstra's framework with an MLP. That comparison is open."
**If pushed.** "I have no evidence it would be worse; my expectation is the friction, close to a sign function, is harder for a polynomial."
