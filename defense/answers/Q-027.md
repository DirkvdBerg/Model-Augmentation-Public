# Q-027 PS initialisation (explain, Hoekstra)
**Problem.** The added states have no data-based start and no direct map to the output; minimising V can reduce the error without capturing the missing dynamics in them (E-106). Without PS the Y error with multisine stays above 50 % (E-123).
**Idea.** Adapted from the two-stage regression of predictive-state learning (Hefny) (E-110).
**S1 (alongside V).** Encoder gives the state at tau from the past window; the augmented model is simulated in closed loop for H samples; the residual y - y_hat is kept fixed (E-111). A temporary decoder maps only the added states to that future residual (E-108); the S1 cost updates only decoder and added-state encoder parameters (E-112), but nothing is frozen: V keeps training all model parameters, the added-state encoder included, in alternation with S1 (E-128). The decoder input is only the added states; the residual target comes from the full model (physical plus added states). Bottleneck: the decoder sees only the added states, so the encoder must store residual-predicting information there (E-113). Ends when the decoder error on left-out records stops improving (E-114).
**S2.** Runs only if the decoder explains at least 10 % of the residual (E-115). Encoder frozen; pairs (state at k, recorded force at k, added state at k+1); g_aug trained by one-step regression to predict the next added state (E-109), no closed-loop simulation, V not minimised (E-116).
**Hand-over.** Continue minimising V from the PS parameters (E-117).
**30 s.** "Stage 1 gives the added states a meaning: they must predict the model's future residual. Stage 2 gives them dynamics: the network learns to predict the next added state. Then normal training continues from there."
**If pushed (why V alone fails).** "The added states have no measured start and no output map, so the network can lower the error by correcting the physical states directly, without using them (E-106)."
