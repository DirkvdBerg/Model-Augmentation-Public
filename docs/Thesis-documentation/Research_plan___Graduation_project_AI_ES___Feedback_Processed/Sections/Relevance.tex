This project fits the AI\&ES domain because it combines:
\begin{itemize}[noitemsep,topsep=2pt]
\item \textbf{AI / data-driven learning:} learning an augmented model from measured data to capture dynamics that are difficult to represent accurately in the first-principles baseline model, including flexible cross-coupling and position-dependent effects.
\item \textbf{Engineering systems:} embedding the learned augmentation within a physics-based LPV-LFR plant model for a real dual-gantry system, accounting for coupling, scheduling dependence, and physical interpretability.
\end{itemize}
