# Reference Map

Maps LaTeX cite keys to PDF file locations and brief descriptions.

PDFs are organized in `literature/` subfolders:
- `literature/gantry/` - system model and hardware specs
- `literature/lpv-lfr/` - LPV and LFR methodology papers
- `literature/augmentation/` - model augmentation framework papers
- `literature/Orthogonality/` - orthogonal projection regularization (the method) and its semiparametric neighbours
- `literature/books/` - textbooks and theses
- `literature/math/` - mathematical references
- `literature/BLA/` - Pintelon and Schoukens, frequency-domain identification (the BLA book)
- `literature/experiment-design/` - excitation design, optimal experiment design, and the 5SMB0 system-identification lectures
- `literature/closed-loop-id/` - closed-loop identification: CLOE family, dual-Youla, informativity, identification for control (2026-08-20 sweep)

**Corrected structural mapping of `schoukens2021ssnn_init` to our augmented block (2026-08-24).** His Eq. (5), the *generalised residual state-space neural network* (gR-SS-NN), contains the same broad idea--an explicit linear recurrence/input path plus a nonlinear residual--but it is **not identical** to our augmented block:

```
Schoukens Eq. (5):  x(k+1)   = A x(k) + B u(k) + nonlinear state residual
                    y(k)     = C x(k) + D u(k) + nonlinear output residual
ours (AB):          x_a[k+1] = A_aa x_a[k] + gamma B_u z[k] + alpha F_a(z[k])
```

The verified sentences below license the **general strategy** of an explicit linear bypass and informed initialization. They do not license each project-specific matrix or claim that `A_aa + B_u` is necessary:

| our element | verified sentence |
|-|-|
| the scheme as a whole | "Some of the neural network weights are initialized starting from a linear approximation of the nonlinear system, while others are initialized using random values or zeros." |
| a live linear input path at init | "It is illustrated in this paper that, together with an improved initialization, the inclusion of the explicit linear part improves the estimation of the SS-NN model significantly." |
| identified linear state-space initialization | "The linear state-space matrices are directly used to initialize the A, B, C, D matrices in eq. (5)." |
| **random `F` behind the zero gate**, rather than Jan's zeroed final layer | "random weights and biases in the nonlinear layer generates a pool of nonlinearly transformed outputs which the estimator can pick from using the linear weights during optimization" |
| what `gamma` is for | "The state-space matrices of the linear approximate model are normalized such that each of the states has a standard deviation equal to 1" |

He also reads the explicit linear part as "a generalized form of a so-called residual network or resNet", which is the same condition `hoekstra2026lfrfp` states as "the learning functions are ResNets" (D-151). His benchmarks are Bouc-Wen and Wiener-Hammerstein, the two carried in `scripts/`.

**Three qualifiers, all of which cut against reading this as a guarantee.**
(a) The table row above already records his empirical result: linear init shrinks the **spread** and speeds convergence, **it does not move the best case much**. So the paper licenses the STRUCTURE and the PROCEDURE; it does not claim the reachable optimum improves. Our case is arguably stronger than his, because C6 measures our poles as unable to adapt at all (`dL/d(nu_log) < 0` with the true mode planted, motion under `0.15 Hz` in 520 updates), so the initialisation is the only chance they get. That is our argument, not his, and must be presented as ours.
(b) `marconato2014init` **contradicts the fourth row for MLP nets**: a linear model plus RANDOM nonlinear units is a weak start and the cure is better *placement* of the units. Our `F` is an MLP. The two papers disagree on this point and the disagreement is unresolved here.
(c) **Material departure:** he initialises a complete `A, B, C, D` realization from the linear model. **Three agents independently reached the same mechanism**, by different routes, and it is the
central result of the sweep: the closed loop reweights the identification criterion by the
sensitivity. Karimi and Landau derive it as the CLOE bias distribution `|S_yp|^2|T_ur|^2`;

carry a `C` factor. Our measured `1.131x` discrimination is the predicted behaviour of this
objective, not a defect.

The relevant controller-effort entries already present in this file are `gautier2013didim`,
`landau2002duality`, and `zang1995iterative`. Together they establish that actuator/input error can
be a better-conditioned closed-loop identification criterion when tight feedback suppresses output
error, and that

```
L = ||e_y||^2 + lambda_u ||C_fb e_y||^2
```

is a controller-shaped output-error criterion rather than an independent measurement. Choosing
`lambda_u` by gradient matching and checking controller gain near 158 Hz are project experiment
choices, not results from those sources.

**Literature-level answer to `A_aa + B_u` versus J1/GRU.** Hoekstra et al.'s published dynamic-parallel augmentation already has `x_bar+ = g_aug(x_tilde,x_bar,u)` without separate `A_aa` or `B_u`; plain J1 restores that model class after changing only the initialization of its augmented output rows. Replacing the feedforward `g_aug` by a GRU is an established system-identification idea and supplies a gated carry path; chrono initialization installs a desired memory range. It therefore replaces `A_aa`'s fixed linear recurrence and `B_u`'s fixed drive by a trainable, state/input-dependent update. It does **not** remove all prior knowledge: the gate bias installs a time scale, and unlike the pole pair it does not install the missing mode's 158 Hz frequency or phase.

The targeted search found each ingredient--Jan-style learned added states, GRU system identification, memory-preserving initialization, stability constraints, and physics-plus-residual GRUs--but not the exact intersection used here: a physics-baseline LFR with added GRU states, no direct `x_a -> y` map, and row-selective zero physical initialization that preserves baseline equality. Treat that combination as a project synthesis, not as proof of architectural novelty or performance.

**Broader gray-box search correction (not author-limited).** The relevant field is considerably
larger than the initial Jan/Schoukens-centered search suggested. Kessels et al. (2025) is the
closest published mechanical construction: it adds encoder-initialized, unmeasured position-
velocity state pairs, learns their governing update and their coupling into the retained physical
equations, trains through truncated open- or closed-loop simulation, and explicitly omits the
output augmentation for its industrial position-output case. Its added-state update is a
structured second-order recurrent model made from feedforward networks, not a GRU. The paper
also uses nonzero writer initialization, selects its initialization scale according to the size of
the baseline discrepancy, and uses linear bypasses in the industrial augmentation networks for
backpropagation conditioning. This makes a Kessels-style second-order cell a more direct
mechanical comparator than treating GRU as the automatic replacement for `A_aa + B_u`.

Independent work fills other pieces of the same problem. Grigorian et al. and Ouala et al. show
that never-observed state trajectories and dynamics can be learned through their effect on
observed trajectories; therefore no direct `x_a -> y` term is required in principle. Dehkordi et
al. show that normalization of the generated hidden-state trajectory can decide whether a
gray-box neural state model trains or diverges. De Groote et al. use one-step pretraining followed
by long-rollout refinement. Lowenstein et al. use a GRU hidden subsystem but jointly estimate its
state and weights by moving-horizon estimation, avoiding exclusive reliance on one long BPTT
chain. Ebers et al. support placing a missing-physics correction in the dynamics rather than in a
trusted measurement map.

None of these papers establishes convergence to the gantry oracle threshold under the project's
specific combination of a `0.121%` open-loop unmodelled fraction, a `0.00217%` closed-loop score,
baseline-preserving zero physical rows, no direct output residual, and a roughly 76-sample
missing-mode horizon. These aggregate percentages must not be interpreted as uniform controller
suppression: the loop suppresses low-frequency motion but amplifies the 158 Hz absorber band
(`sigma_max(S_o) = 1.81` near 157.89 Hz). The
defensible research gap is therefore **conditioning and trainability of a baseline-preserving
latent state extension in the small-residual closed-loop regime**, not the broad idea of neural
gray-box state extension itself.

**Mechanical grey-box boundary identified by Noel and Schoukens (2018).** This paper is close in
application domain but not in latent-state architecture. It uses a state-space model of sufficient
order and assumes that the missing effect is a spatially localised nonlinear restoring force whose
location and basis family can be supplied from mechanics. The nonlinear regressors are measured
displacements/velocities during FNSI initialization and the model's own outputs in autonomous
simulation; the subsequent output-error optimization removes the errors-in-variables bias caused
by using noisy measured outputs as initial regressors. This is a strong precedent for **structured
initialization followed by simulation refinement**, and it suggests a useful non-neural comparator
when the residual is a known local spring/damper law. It cannot create or learn an unspecified
missing mechanical degree of freedom by itself. For the gantry's missing 158 Hz mode, Kessels-style
state extension remains the closer model class; Noel-Schoukens mainly supports exploiting
mechanical localization and avoiding an unnecessarily general multivariate neural correction.

**Project synthesis, not a literature theorem.** Row-selective initialization is the minimal test
of the dead-state mechanism, and the gantry smoke tests confirm that it makes `x_a` live and
load-bearing. A chrono-initialized GRU remains a controlled candidate, not an already validated
replacement for `A_aa + B_u`; exact dense-lag diagnostics and matched held-out training are still
needed. No direct `x_a -> y` map is
required: `x_a` can affect position through future physical-state corrections. Noiselessness removes
a statistical noise floor, but not non-convex optimization, inadequate excitation, closed-loop
attenuation, or recurrent credit-assignment problems.
