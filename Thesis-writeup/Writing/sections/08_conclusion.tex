For the dual-drive gantry,
a parallel augmentation with added states
is able to capture the vibration mode of the added mass, spring and damper when
it is trained in closed loop with the known controller and
the added states are initialised with PS.
The resulting model reduces the prediction error on $Y$
when this mode is sufficiently excited in the data.
The final model performs slightly worse than the baseline model on records without
multisine excitation.
The model generalises to held-out positions and unseen motion profiles:
the prediction errors on the interpolation and extrapolation records are similar,
and the final model performs better than the black box model on average.
Compared to unconstrained estimation,
OBC is able to reduce the overlap between the neural network and the parameter directions.
However, the parameter estimates still deviate from their true
values and depend on where training starts.
In conclusion, a parallel augmentation with added states initialised with
PS improves the prediction of the gantry, but the uniqueness provided by
OBC for a single state update does not make the trained parameters
interpretable as defined in Section~\ref{sec:intro}.
These results are limited to simulation with one controller.
