## 5. Established implementation facts

### 5.1 State model

The model retains Hoekstra's physical plus augmentation state:

```text
x_k = col(x_b,k, x_a,k)
```

Here `x_b` contains six physical gantry states and `x_a` contains the learned dynamic states. The
physical block is `Reduced_Gantry_State_Block`. The ANN writes a contribution into routed physical
rows and updates its additional-state rows.

The baseline has zero contribution in the additional-state rows. Those rows are orthogonal to the
baseline directions in the one-step state-space stacking by their disjoint coordinates. This does
not make their future physical-output effects orthogonal after state propagation.

### 5.2 Ten identifiable coordinates

The physical block is parameterized by ten identifiable combinations:

```text
[kb_sum, cg1, cg2, cy, cb_sum, mh, m_total, m_diff, J_eff, d]
```

Nine use logarithmic free coordinates and `m_diff` uses a bounded relative-linear coordinate. The
projection protects directions generated by these ten free coordinates. It does not operate on the
fourteen original raw parameters.

### 5.3 Fixed reference tuples

The reference set uses every valid sample in the fourteen training records:

```text
q_k       = P^{-T} y_k
qdot_k    = fourth-order central difference of q_k within each record
x_a,k     = 0
u_k       = recorded u_total after the pipeline's block-mean resampling
```

Two boundary samples are removed at each end of every record. The stencil never crosses a record
boundary. These tuples are normalized using the same coordinates as the model.

The encoder does not construct this OBC reference set. The encoder still initializes the state of
the actual training rollout. Finite differences reconstruct only the unmeasured velocity in the
fixed OBC reference tuples.

### 5.4 Baseline tangent basis

At the detached epoch expansion point `vbar`, the implementation forms

```text
J_b,k = d f_base^d(v, x_b,k, u_k) / d v evaluated at vbar
J     = col_k rows_routed(J_b,k)
```

`f_base^d` is the complete normalized RK4 state transition. `J` has ten columns and one row for
each selected physical state contribution at every reference sample.

This is the critical substitution for Györök's regressor:

```text
Györök: Phi                  gantry: J
exact linear parameter span          local parameter tangent space
```

The implementation uses `torch.func.jacfwd` in float64 and an economy SVD. It never forms the Gram
matrix for the solve.

### 5.5 ANN field and coefficient

Evaluate the current ANN on the same fixed reference set with `x_a=0`, retain the routed physical
rows and stack them sample-major:

```text
F_aug(theta_a) = col_k f_aug^b(x_b,k, 0, u_k; theta_a)
```

With `J = U S V^T`, the auxiliary coefficient is

```text
theta_aux = J^+ F_aug = V S^{-1} U^T F_aug
```

and the stacked corrected field is

```text
F_tilde = F_aug - J theta_aux
J^T F_tilde = 0
```

The SVD factors are fixed during an epoch. `theta_aux` is recomputed once per objective evaluation
from the current ANN and remains differentiable with respect to ANN parameters.

### 5.6 Pointwise rollout correction

At each rollout point, the physical ANN contribution is corrected by

```text
f_tilde_aug^b(x_k, u_k)
    = f_aug^b(x_k, u_k) - J_b(vbar, x_b,k, u_k) theta_aux
```

The coefficient is reused across all timesteps in that objective. The state-dependent directional
derivative is implemented by the exact hand-written forward tangent through RK4. The
parameter-to-matrix directional derivative is computed once per objective outside the compiled
step. Finite differences are test oracles only and never enter training.

The ANN's additional-state rows pass through unchanged.

### 5.7 Lifecycle and controller

The fixed reference tuples remain fixed for the run. At each epoch boundary, `J` is rebuilt at the
current detached physical parameter vector and then held during that epoch. Every objective
evaluation recomputes `theta_aux` because the ANN weights may have changed.

The actual training rollout remains closed loop. The controller determines the sequence of inputs
seen during the rollout, but its Jacobian is absent from `J`. The OBC condition concerns one plant
state transition at fixed `(x_b,k, u_k)` reference tuples.

### 5.8 Scope of the achieved condition

The implementation establishes only

```text
stacked one-step orthogonality
on the fixed reference tuples
in normalized routed physical-state coordinates
against the local ten-parameter tangent space at vbar
on the reference slice x_a = 0
```

It does not establish pointwise orthogonality, global orthogonality in physical parameters,
orthogonality for nonzero augmentation states, multistep orthogonality, closed-loop input-output
orthogonality, stability, consistency, covariance preservation or unique recovery under Györök's
theorems.

## 6. What differs from Györök

The walkthrough must distinguish these differences rather than describing the code as a direct
copy:

1. Györök uses a finite-memory discrete-time input-output model. The gantry uses a physical
   discrete-time state transition obtained by RK4 from a continuous-time LPV model.
2. Györök's baseline is linear in its parameters, so `Phi` is an exact global parameter regressor.
   The gantry transition is nonlinear in the reduced free parameters, so `J` is a local first-order
   parameter sensitivity.
3. Györök stacks measured input-output regressors. The gantry stacks data-derived physical-state
   reference tuples because velocities are unmeasured.
4. Györök has one learned output contribution. The gantry ANN has physical-state and
   additional-state contributions. Only the physical rows share coordinates with the baseline.
5. Györök's prediction subtraction evaluates the baseline regressor at a new point. The gantry
   evaluates a transition directional derivative at each rollout point using the epoch expansion
   point and the current state and input.
6. The gantry trains in closed loop, but the controller is outside the one-step orthogonality
   definition.
7. The gantry basis moves at epoch boundaries because its tangent space depends on the physical
   parameter estimate. Györök's exact regressor does not need this parameter-dependent refresh.

The local Taylor expansion is with respect to the ten physical free parameters. Scheduling position
`Y` is evaluated at each reference state and rollout state. Do not describe the implementation as
Taylor-expanding `Y` unless the code proves such an expansion exists.

## 7. Numerical evidence already available

The complete reference set contains 671,944 tuples and 4,031,664 routed rows. It has numerical rank
ten at both nominal and ten-percent-detuned parameter points. The raw condition number is about 766
nominal and 893 detuned. After column normalization it is about 10.5 and 12.5. The weakest
separation is `cg1` versus `cg2`, with correlation near minus 0.98.

The measured full-set rollout-path orthogonality residual is `5.8e-8`, within the declared
float32 floor. A stale coefficient after an optimizer update gives `2.8e-3`, which demonstrates why
the coefficient must be recomputed each objective.

The nominal baseline tangent contains about 20 percent of the measured one-step discrepancy. At
the detuned starting point it contains about 86 percent because the discrepancy is dominated by
physical parameter error. These `rho` values describe overlap before subtraction and do not prove
whether training will improve parameter recovery.

The behavioral tests establish coefficient lifecycle, ANN gradient flow, additional-state
passthrough, disabled-path equivalence, physical-parameter gradients and checkpoint behavior. No
training result exists.
