04The core visual idea is a Hankel data matrix, past columns left and residual columns right, joined only through a thin x̄ column: S1 is a rank bottleneck, S2 uses that row τ+1 is row τ shifted one column.
S1 ψa p χτ (lags −30…−1) eτ (0…H−1) x̄τ|τ τ ↓ y − ŷ
minθp, θaenc Στ ‖p(ψa(χτ)) − eτ‖²
eτ = [yτ − ŷτ|τ, …, yτ+H−1 − ŷτ+H−1|τ],  x̄τ|τ = ψa(χτ)
S2 χ rows uτ x̄ column x̄τ|τ = ψa(χτ) ψa(χτ+1) gaug(x̂τ|τ, uτ) τ τ+1
minθaug Στ ‖gaug(x̂τ|τ, uτ) − ψa(χτ+1)‖²
target ψa(χτ+1) = x̄τ+1|τ+1 held fixed; only θaug trained
S1 builds
  1. Past block: one row per τ, columns lags −30…−1; the diagonal stripes show it is one signal, shifted per row.
  2. Residual block eτ with its y − ŷ icon, same rows.
  3. Thin x̄ column between them (highlight); ψa arc from the past block.
  4. Dashed p arc to the residual block; one row outlined; S1 minimisation appears.
S2 builds
  1. Past block alone; row τ outlined grey.
  2. Row τ+1 outlined in highlight; short diagonal ticks join equal samples: row τ+1 is row τ shifted one column.
  3. The x̄ column: row τ grey (fixed), row τ+1 bold outline (target).
  4. uτ cell and gaug loop from row τ to row τ+1 (highlight); S2 minimisation appears.
Answers best: the one-sample shift (Hankel diagonals) and the bottleneck argument familiar to subspace identification. Weakest: the residual is a block of grey cells, far from the slide-13 gap; needs a matrix-literate audience.
