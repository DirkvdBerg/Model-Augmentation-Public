00015 [PDF p.1]                                           Abstract


00016 [PDF p.1]                                           Parameter identifiability is a structural property of an ODE model for recovering the values of parameters from the


00017 [PDF p.1]                                           data (i.e., from the input and output variables). This property is a prerequisite for meaningful parameter identification


00018 [PDF p.1]                                           in practice. In the presence of nonidentifiability, it is important to find all functions of the parameters that are identi-


00019 [PDF p.1]                                           fiable. The existing algorithms check whether a given function of parameters is identifiable or, under the solvability


00020 [PDF p.1]                                           condition, find all identifiable functions. However, this solvability condition is not always satisfied, which presents


00021 [PDF p.1]                                           a challenge. Our first main result is an algorithm that computes all identifiable functions without any additional as-


00022 [PDF p.1]                                           sumptions, which is the first such algorithm as far as we know. Our second main result concerns the identifiability


00023 [PDF p.1]                                           from multiple experiments (with generically different inputs and initial conditions among the experiments). For this


00024 [PDF p.1]                                           problem, we prove that the set of functions identifiable from multiple experiments is what would actually be computed


00025 [PDF p.1]                                           by input-output equation-based algorithms (whether or not the solvability condition is fulfilled), which was not known


00026 [PDF p.1]                                           before. We give an algorithm that not only finds these functions but also provides an upper bound for the number of


00027 [PDF p.1]                                           experiments to be performed to identify these functions. We provide an implementation of the presented algorithms.


00028 [PDF p.1]                                           Keywords: parameter identifiability, multiple experiments, input-output equations, differential algebra, characteristic


00029 [PDF p.1]                                           sets

00033 [PDF p.1]                                           1. Introduction


00034 [PDF p.1] 


00035 [PDF p.1]                                               In this paper, we study structural parameter identifiability of rational ODE systems. Roughly speaking, a param-


00036 [PDF p.1]                                           eter is structurally identifiable if its value can be recovered from the observations assuming continuous noise-free


00037 [PDF p.1]                                           measurements and sufficiently exciting inputs (also referred to as the persistence of excitation, see [21, 43]). If not all


00038 [PDF p.1]                                           of the parameters of a model are identifiable, the next question usually is what rational functions h(µ̄) ∈ C(µ̄) of the


00039 [PDF p.1]                                           parameters µ̄ are identifiable. The knowledge of identifiable functions can be used in these ways:


00040 [PDF p.1]                                               • If the functions of interest to the modeler are identifiable, then the lack of identifiability of some parameters is


00041 [PDF p.1]                                                  not an issue (sometimes, this is even an advantage [38]).


00042 [PDF p.1]                                               • Identifiable functions can be used to find an identifiable reparametrization of the model [1, 23, 24], which is a


00043 [PDF p.1]                                                  way of improving the model.


00044 [PDF p.1]                                               • Knowledge of identifiable functions can be used to discover parameter transformations that preserve the input-


00045 [PDF p.1]                                                  output behavior and thus could provide additional insights to the modeler (see Section 5.2).


00046 [PDF p.1]                                               To the best of our knowledge, all existing approaches to computing identifiable functions extract them from the


00047 [PDF p.1]                                           coefficients of input-output equations (going back to [29]; for a concise summary, we refer to [31, Introduction and


00048 [PDF p.1]                                           Algorithm II.1]). To conclude that the coefficients of an input-output equation are identifiable, one can, for example,
