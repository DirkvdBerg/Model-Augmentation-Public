Optimal Output Normalization Strategies for Multi-Trajectory Grey-Box Parameter RecoveryIntroductionThe accurate recovery of physical parameters within dynamic systems represents a cornerstone of modern control theory, system identification, and physics-informed machine learning. When the underlying process is modeled as a continuous-time, quasi-Linear Parameter-Varying (LPV) state-space system, the identification task transcends mere predictive accuracy. The primary objective is to deduce the true numerical values of strictly physical parameters—such as masses, stiffnesses, and damping coefficients—that govern the system's differential equations. Achieving this requires robust optimization techniques, typically involving the integration of the dynamic equations over short temporal segments via methods like the 4th-order Runge-Kutta (RK4) algorithm. This approach aligns directly with the multiple shooting paradigm utilized in modern nonlinear optimal control.A profound complexity arises when this parameter recovery is driven by heterogeneous, multi-trajectory datasets. Experimental data inherently contains variations in excitation; in a multi-degree-of-freedom system with output channels such as displacements $X_1$, $X_2$, and $Y$ measured in metres, specific experimental runs may isolate certain dynamics. For instance, some trajectories may excite exclusively the $Y$ channel while $X_1$ and $X_2$ remain physically constrained to near-constant values, whereas other trajectories may excite all channels simultaneously.When training such a model using gradient-based optimization algorithms like Adam, the formulation of the Mean Squared Error (MSE) loss function becomes the critical determinant of algorithmic success or failure. The core problem lies in the normalization of the output channels within the MSE calculation. Improper scaling dictates erroneous gradient propagation, resulting in pathological optimization landscapes, severe parameter bias, and fundamental identifiability failures. Muting a channel that provides critical zero-excitation constraints can lead to the false identification of cross-coupling parameters, while over-amplifying sensor noise in dormant channels can cause the optimizer to wander endlessly.This exhaustive report provides a rigorous theoretical and practical analysis of output channel normalization for multi-trajectory grey-box parameter recovery. By synthesizing paradigms from classical system identification, nonlinear optimal control, multiple shooting frameworks, and statistical estimation theory, this document addresses the theoretical validity and practical implications of various normalization strategies. It directly evaluates the user's proposed options—global signal variance scaling, per-trajectory variance scaling, initial-prediction-error scaling, and unnormalized approaches—and establishes concrete, theoretically optimal recommendations for achieving unbiased parameter recovery.1. Theoretical Foundations in System IdentificationIn the domain of system identification, established by foundational literature from Ljung, Söderström, Stoica, and Van den Hof, the selection of the loss function and its associated weighting matrix is governed by the principles of the Prediction Error Method (PEM) and Maximum Likelihood Estimation (MLE).1.1 The Prediction Error Method and Output WeightingFor a multi-output dynamic system, the standard PEM loss function $V(\theta)$, parameterized by the physical parameter vector $\theta$, is formulated as a weighted sum of squares of the prediction errors. The generalized formulation is:$$V(\theta) = \frac{1}{N} \sum_{t=1}^{N} e(t, \theta)^T W(\theta) e(t, \theta)$$where $N$ is the number of data samples, $e(t, \theta)$ is the $n_y \times 1$ error vector at time $t$ generated by the simulated model outputs against the measured trajectories, and $W(\theta)$ is a positive semidefinite weighting matrix. The standard practice for multi-output estimation is to utilize a weighting matrix that dictates the relative importance of the outputs to ensure that channels with naturally larger magnitudes do not overwhelmingly dominate the gradient descent trajectory.Within established commercial and academic toolboxes, such as the MATLAB System Identification Toolbox developed by Ljung, the manipulation of this weighting matrix is handled via the OutputWeight property. The absolute theoretical recommendation is to set this weight inversely proportional to the reliability of the data—specifically, the inverse of the noise covariance matrix.When the exact noise characteristics are unknown a priori, the standard software recommendation is to utilize an automated weighting mechanism. By setting OutputWeight to 'noise', the identification algorithm minimizes the determinant of the sample covariance matrix of the prediction errors :$$V(\theta) = \det \left( \frac{1}{N} \sum_{t=1}^{N} e(t, \theta) e(t, \theta)^T \right)$$This determinant minimization is mathematically equivalent to iteratively updating the weighting matrix $W(\theta)$ as the inverse of the estimated variance of the error. Under the assumption of Gaussian-distributed measurement noise, this trace-determinant formulation ensures that the resulting parameter estimate is optimal in the maximum likelihood sense.1.2 The Fallacy of Signal Variance WeightingA crucial distinction in classical system identification theory is the difference between signal variance and noise variance. The variance of the underlying physical signal (the amplitude of the measured $X_1$, $X_2$, or $Y$ trajectories) is an artifact of the experimental input design and the external excitation applied to the system. It is not a measure of data reliability.Standardizing the loss function by dividing by the signal variance is actively discouraged in rigorous system identification when attempting to recover physical parameters. If a specific channel possesses a high signal variance, it inherently contains a higher signal-to-noise ratio (SNR) and therefore carries significantly more information regarding the physical parameters that govern its dynamics. Down-weighting this channel by dividing by its large standard deviation artificially diminishes the influence of the most informative data in the optimization process. Conversely, if a channel is physically unexcited (exhibiting near-zero signal variance), dividing by this tiny variance amplifies the pure measurement noise, forcing the optimizer to fit parameters to stochastic sensor fluctuations rather than underlying physics.1.3 Handling Multi-Experiment Heterogeneous DataWhen dealing with multiple trajectories (often termed multi-experiment data in the literature), standard practice dictates grouping the disparate datasets into a unified structure (e.g., the iddata object) while estimating a single, globally consistent parameter vector.The treatment of the weighting matrix across these heterogeneous experiments depends entirely on the characteristics of the data acquisition hardware. If the measurement noise (the sensor noise floor) is constant across all experiments—which is almost universally the case unless different sensor hardware is swapped between runs—the standard recommendation is to utilize a single, global weighting matrix based on that constant noise variance.In scenarios where heterogeneous multi-trajectory data lacks persistent excitation in certain channels (e.g., $X_1$ and $X_2$ are physically fixed during a specific test run), classical literature asserts that these unexcited channels still provide indispensable physical constraints. A constant, near-zero channel contains valuable information; it requires the optimizer to ensure that cross-coupling parameters (such as off-diagonal stiffness matrix entries in a mechanical LPV model) correctly predict zero displacement when orthogonal channels are heavily excited. Applying an unprincipled normalization scheme that blinds the loss function to these zero-excitation constraints reliably leads to the identification of phantom cross-coupling dynamics.2. Scaling in Multiple Shooting and Direct Collocation FrameworksIn the domains of dynamic optimization, direct multiple shooting, and direct collocation—paradigms pioneered and refined by researchers such as Bock, Diehl, and Biegler—parameter estimation is formulated as a highly structured, large-scale Nonlinear Programming (NLP) problem. The user's methodology of integrating the continuous-time quasi-LPV system via RK4 over short temporal segments perfectly aligns with the direct multiple shooting methodology, wherein continuity constraints link the segments.2.1 The Algorithmic Imperative of Hessian ConditioningIn direct multiple shooting frameworks like CasADi (which heavily interfaces with the IPOPT interior-point solver) or MUSCOD-II, scaling the least-squares objective is not merely a statistical consideration; it is an absolute algorithmic imperative. Interior-point methods, as well as Sequential Quadratic Programming (SQP) algorithms like those used in DynOpt, rely heavily on the condition number of the Karush-Kuhn-Tucker (KKT) matrix and the exact Hessian of the Lagrangian.If the output signals possess vastly different amplitudes—for example, if $X_1$ oscillates between $-10.0$ and $10.0$ metres while $Y$ is constrained to micro-vibrations between $-0.001$ and $0.001$ metres—the unscaled Hessian of the objective function becomes pathologically ill-conditioned. The eigenvalues of the Hessian will span multiple orders of magnitude.CasADi users and NLP developers universally emphasize that poor scaling is the primary cause of convergence failure, maximum iteration limits being reached, or exceedingly slow optimization in parameter estimation tasks. The fundamental algorithmic recommendation across all these tools is to scale both the decision variables (the parameters) and the objective function residuals such that their numerical values fall comfortably within the range of $0.01$ to $100$.2.2 Relative Output Parametric Sensitivity (ROPS)In advanced multiple shooting parameter estimation, Biegler and colleagues highlight the importance of "Relative Output Parametric Sensitivity" (ROPS) when dealing with heterogeneous data. The ROPS matrix, $s_{i,j}$, normalizes the absolute sensitivities of the outputs with respect to the parameters to create dimensionless quantities:$$s_{i,j}(t) = \frac{\partial y_i(t)}{\partial p_j} \frac{p_j}{y_i(t)}$$This sensitivity analysis is utilized to determine which parameters are structurally estimable given a specific trajectory. In practice, the objective function terms in multiple shooting are scaled relative to the expected nominal values of the outputs or, more rigorously, the measurement uncertainties.When different experiments excite different subsets of outputs, applying a global static normalizer based purely on maximum signal amplitude (as in Option A) creates structural rank deficiencies in the Hessian for trajectories where the signal is dormant. Bock's adaptively scaled Gershgorin method and related NLP scaling strategies favor scaling based on the measurement error bounds or the expected prediction error, rather than raw signal variance. If a signal is physically constant in an experiment, the multiple shooting constraint simply enforces that the RK4 integration yields a constant value. The associated objective penalty for deviating from this constant should be scaled by the tolerance of the numerical integrator and the known sensor noise, ensuring that the NLP solver does not arbitrarily ignore the constraint simply because the global signal amplitude across other trajectories is massively larger.2.3 The RIMSPE Method for Heterogeneous TrajectoriesTo handle heterogeneous multi-trajectory data in parameter estimation specifically for processes where sensitivities change drastically over the operating trajectory, the literature proposes methods such as the Ranked-Interval Multiple Shooting Parameter Estimation (RIMSPE) technique.In RIMSPE, the measured operating trajectory is segmented (analogous to the batched shooting described in the query). For each segment, a sensitivity analysis utilizing Gram-Schmidt orthogonalization identifies the most contributing parameters. Crucially, to handle heterogeneous reliability without breaking the global optimization, the method utilizes a weighted average across segments based on the normalized element-wise inverse of the vector of variances (the Fisher Information). Information-Theoretic and Statistical FoundationsTo ascertain the mathematically optimal normalization strategy, the principles of statistical estimation theory, specifically Maximum Likelihood Estimation (MLE) and the Fisher Information Matrix (FIM), must be rigidly applied to the multi-trajectory grey-box scenario.3.1 Maximum Likelihood and the Inverse Noise VarianceUnder the fundamental assumption that the measurement noise for each output channel is independent and follows a Gaussian distribution with a zero mean and a covariance matrix $\Sigma$, the Maximum Likelihood Estimator is mathematically identical to the Weighted Least Squares (WLS) estimator. In this optimal formulation, the weighting matrix $W$ is the strict inverse of the noise covariance, $W = \Sigma^{-1}$.The objective function to be minimized is:$$\hat{\theta}_{MLE} = \arg\min_{\theta} \sum_{t=1}^{N} (y_t - \hat{y}_t(\theta))^T \Sigma^{-1} (y_t - \hat{y}_t(\theta))$$This theorem provides a definitive and theoretically unassailable answer to the third question posed in the research query: Normalizing the squared errors by the noise variance of each channel yields the maximum likelihood estimator. This is the universally recommended approach in statistical modeling. It extends naturally and seamlessly to the multi-experiment case because the fundamental stochastic properties of the sensors (and therefore $\Sigma$) generally remain constant regardless of whether the physical system is executing a highly dynamic trajectory or remaining perfectly still.Statistical theory exhaustively demonstrates that weighting the loss function by the signal variance (as proposed in Options A and B) is fundamentally flawed from an information-theoretic perspective. Normalizing by the physical variance of the trajectory breaks the linkage between the loss function and the true negative log-likelihood of the data generation process.3.2 The Fisher Information Matrix (FIM) and the Cramér-Rao BoundThe Fisher Information Matrix quantifies the exact amount of information that observable random variables carry about an unknown parameter vector $\theta$. The Cramér-Rao lower bound, a foundational theorem in parameter estimation, establishes that the inverse of the FIM constitutes the absolute lower bound on the covariance matrix of any unbiased estimator.In a multi-trajectory parameter recovery setting, the total Fisher Information is simply the algebraic sum of the Fisher Information extracted from each independent trajectory. The components of the FIM are heavily dependent on the partial derivatives of the output with respect to the parameters (the parametric sensitivities) mathematically weighted by the inverse noise covariance.If a normalization scheme arbitrarily alters the relative weights of the channels inconsistently with the true noise covariance (for example, by using mini-batch specific trajectory variances as proposed in Option B), it violently distorts the Fisher Information. The resulting estimator is no longer efficient; it will fail to reach the Cramér-Rao lower bound, and the recovered physical parameters will exhibit unnecessarily high variance, instability, and severe potential bias.3.3 Hellinger Localization in Multi-Trajectory DataRecent mathematical advancements in sequential learning and multi-trajectory parameter recovery rely heavily on the Hellinger localization framework. Theoretical bounds for multi-trajectory maximum likelihood estimation demonstrate that instance-optimal parameter recovery scales with the full data budget $mT$ (where $m$ is the number of trajectories and $T$ is the temporal length of each trajectory), provided the MLE formulation is strictly adhered to.The theoretical bounds derived via Hellinger localization perfectly match the rates prescribed by the asymptotic normality of the MLE because the localization acts as a quadratic form in parameter space weighted exactly by the Fisher Information Matrix of the underlying path measure. To achieve this theoretical optimality in practice—specifically when utilizing a grey-box quasi-LPV model trained via the Adam optimizer—the loss function must serve as a mathematically valid surrogate for the negative log-likelihood.This strictly dictates that the normalizer must be a consistent, global estimate of the data generation process's uncertainty (encompassing both sensor noise and inherent structural mismatch), completely independent of the transient physical signal variance of any specific trajectory. Adapting the normalizer to fit the local signal amplitude destroys the path measure equivalency required by Hellinger localization.4. Rigorous Evaluation of Output Normalization StrategiesGiven the formidable theoretical framework established via system identification, optimal control, and statistical information theory, the four normalization options proposed for the heterogeneous quasi-LPV system can be critically and exhaustively evaluated.4.1 Critique of Option A: Global Sigma (Signal Standard Deviation)Mechanism: Computing the per-channel standard deviation over all concatenated trajectories and utilizing it as a fixed normalizer throughout training.Analysis: This approach suffers from a fatal conceptual flaw: it conflates physical signal variance with measurement uncertainty. As correctly hypothesized in the initial query, if the concatenated dataset is numerically dominated by trajectories where the $Y$ channel is highly excited, $\sigma_Y$ will be a large scalar value. Conversely, during an $X$-only trajectory, the $Y$ channel should ideally trace a flat line at a constant position (subject only to sensor noise). Because the global $\sigma_Y$ is artificially massive (pulled up by the dynamic trajectories), the loss function applies a near-zero relative weight to the $Y$ prediction errors during the $X$-only trajectory.This creates a catastrophic identifiability problem. In a multi-DOF mechanical or mechatronic quasi-LPV system, cross-coupling parameters (e.g., off-diagonal mass or stiffness matrix terms) dictate how kinetic energy in $X$ leaks into $Y$. If the $Y$ error is effectively muted by the normalization on an $X$-only trajectory, the optimizer receives virtually zero gradient penalty for predicting physically erroneous cross-coupling. The model will effortlessly learn a physically incorrect parameter that allows $X$ dynamics to bleed into $Y$, simply because the loss function is mathematically "blind" to $Y$ errors in that specific trajectory. Option A is fundamentally disconnected from the physical grounding of the system and will lead to severely biased physical parameters.4.2 Critique of Option B: Per-Trajectory SigmaMechanism: Computing the per-channel standard deviation for each trajectory individually, employing a noise floor to prevent division by zero, and allowing segments sampled from a trajectory to utilize that specific trajectory's sigma.Analysis: While this option attempts to resolve the "blindness" issue inherent in Option A, it introduces a fatal flaw regarding the mechanics of gradient-based optimization using the Adam algorithm. In a multiple-shooting or batched training paradigm, mini-batches will consist of segments randomly sampled from different, heterogeneous trajectories. If different segments carry drastically different normalization scales, the MSE loss combines totally heterogeneous units.The Adam optimizer relies heavily on tracking the first moment (the exponential moving average of the gradient, $m_t$) and the second moment (the exponential moving average of the squared gradient, $v_t$) to compute adaptive learning rates for the 13 physical parameters. The update rule is governed by $\theta_{t+1} = \theta_t - \frac{\eta}{\sqrt{\hat{v}_t} + \epsilon} \hat{m}_t$.If the scale of the loss function jumps erratically from batch to batch because of per-trajectory normalization (e.g., an $X$-only batch has a massive weight on $Y$ due to the noise floor, while a $Y$-active batch has a tiny weight on $Y$), the variance of the gradients $\nabla_\theta L$ explodes. The second moment estimate $\hat{v}_t$ will become dominated by the maximum scaling instances, effectively killing the learning rate for "normal" batches and corrupting the momentum terms. This leads to erratic parameter wandering and failure to converge. Furthermore, from a statistical perspective, changing the objective function weighting per trajectory violates the fundamental assumption of a unified Maximum Likelihood Estimator, guaranteeing biased parameter recovery.4.3 Critique of Option C: Per-channel RMSE of the Initial ModelMechanism: Executing a forward pass of the model at its initial, detuned parameters to measure the per-channel RMSE on each trajectory, and utilizing this as the normalizer.Analysis: This strategy possesses significant theoretical merit and closely mirrors established, successful techniques in both system identification and physics-informed machine learning. In the literature concerning building energy modeling (e.g., IPMVP Option C and ASHRAE Guideline 14), baseline models are routinely calibrated by evaluating the Coefficient of Variation of the Root Mean Square Error (CV(RMSE)) to normalize initial errors and assess parameter estimability.In the context of gradient descent optimization, normalizing by the initial prediction error acts as a highly effective global preconditioner. It mathematically ensures that at epoch 0, the total loss contribution originating from each channel is exactly $1.0$ (or a fixed, scaled constant). This structural guarantee ensures that the optimizer begins its descent by paying equal geometric attention to the physical parameters governing $X_1$, $X_2$, and $Y$.However, applying this per-trajectory inherits the identical mini-batch gradient inconsistency problem detailed in Option B. The superior, theoretically sound formulation of Option C is to utilize the Global Initial RMSE (the RMSE of the initial model across all concatenated data) as a fixed, global normalizer. This approach is highly effective for grey-box models because it inherently accounts for both the measurement noise covariance and the initial structural model mismatch, effectively executing the first step of an Iteratively Reweighted Least Squares (IRLS) algorithm.4.4 Critique of Option D: No NormalizationMechanism: Utilizing raw MSE in $\text{metres}^2$, accepting that channels with larger amplitude excursions will dominate the loss function.Analysis: Unnormalized MSE is mathematically equivalent to the Maximum Likelihood Estimator if and only if all three output channels share the exact same measurement noise variance, and the model structurally matches the true physics perfectly. In reality, grey-box quasi-LPV models inevitably suffer from unmodeled dynamics and approximation errors.If channel $X_1$ exhibits large amplitude excursions (e.g., $\pm 2.0$ m) while $Y$ exhibits small functional excursions (e.g., $\pm 0.1$ m), the raw squared errors in $X_1$ will mathematically dwarf the errors in $Y$ by orders of magnitude. The Adam optimizer, seeking the path of steepest descent, will dedicate its entire algorithmic capacity to fitting parameters related to $X_1$. It will leave $Y$-related parameters—and vitally, cross-coupling parameters—essentially abandoned at their initial guesses. This raw amplitude domination leads directly to the non-identifiability of a substantial subset of the 13 physical parameters. Furthermore, when parameters are reparameterized in log-space ($\theta = \exp(\phi)$), the chain rule ensures that the unscaled gradients will cause massive, destabilizing updates to parameters affecting large outputs.5. Global vs. Per-Experiment Normalizers in Multi-Trajectory FrameworksThe specific handling of multi-experiment normalizers in established optimization and simulation frameworks provides actionable guidance for the practical implementation of the quasi-LPV training loop.5.1 CasADi, IPOPT, and DynOptIn state-of-the-art optimal control frameworks like CasADi (which interfaces with the IPOPT interior-point solver) and DynOpt, the objective function must be scaled to avoid ill-conditioning, but this scaling must remain invariant to the decision variables and absolutely constant throughout the NLP solver's iterations.For multi-experiment parameter estimation formulated in CasADi, practitioners universally define a single, global symbolic objective function. The firmly recommended scaling technique is to normalize the residual of each channel by the expected order of magnitude of the maximum allowable error—which aligns perfectly with the measurement noise floor or the desired prediction tolerance—rather than the variance of the physical signal. This strategy mathematically guarantees that the Hessian maintains a stable condition number regardless of which trajectory is currently being evaluated.5.2 PRISM and Sequence NormalizationIn specific parameter recovery and advanced simulation modeling tools like PRISM, sequences or trajectories are routinely normalized by a maximum attainable theoretical score or a globally defined mathematical constant. The PRISM architecture preserves the relative probability distribution across different operating conditions (or trajectories) by strictly avoiding dynamically shifting local normalizers. Shifting normalizers per trajectory would destroy the mathematical consistency of the global recovery, leading to divergent and physically meaningless parameter estimates.6. Identifiability Failures and Remedies in the LiteraturePublished results across system identification, aerospace engineering, and building energy modelling explicitly demonstrate that poor normalization choices in multi-trajectory parameter recovery lead directly to identifiability failures and severe bias.6.1 The Impact of Incorrect Output ScalingWhen normalization is tied to signal variance rather than noise variance or initial model error, parameters governing lower-amplitude dynamics become practically unidentifiable. A comprehensive study on grey-box parameter estimation for dynamic biological systems highlighted that attempting to scale simulations to match data using estimated local scaling factors, rather than normalizing based on the baseline data reliability (DNS vs. SF), severely degraded parameter identifiability and estimation performance.Similarly, in aerospace applications involving parameter estimation from flight test data (e.g., 5-hole Pitot tube calibration), researchers found that using estimators with poorly scaled objective functions frequently converged to incorrect local minima. This occurred because the normalization suppressed the vital sensitivities associated with cross-coupled dynamics (such as the steady wind vector versus the airspeed scale factors), allowing the optimizer to ignore fundamental physical constraints.In building energy modeling utilizing RC (resistor-capacitor) grey-box models, researchers note that when operational data lacks sufficient spectral excitation (analogous to the unexcited channels in the heterogeneous trajectories), parameters frequently converge to physically implausible values if the loss function is not strictly regularized and globally scaled by baseline expectations.6.2 Recommended Remedies for Parameter BiasTo ensure accurate physical parameter recovery in heterogeneous multi-trajectory settings, the literature recommends several specific remedies:Iterative Covariance-Weighted Estimation (IRLS): If the exact noise covariance of the $X_1, X_2, Y$ sensors is unknown, it should be estimated iteratively. The process begins with an unweighted (or Initial-RMSE weighted) least squares pass. After convergence, the sample variance of the residuals for each channel across all trajectories is calculated. The inverse of these residual variances becomes the fixed, global weighting matrix for the next training phase. This proven algorithm converges mathematically to the Maximum Likelihood Estimator.Relative Output Parametric Sensitivity (ROPS) Verification: Prior to initiating gradient descent, the ROPS matrix should be computed to mathematically verify that all 13 physical parameters are structurally identifiable across the concatenated trajectories. If certain parameters only influence the $Y$ channel, the global weight for $Y$ must be sufficient to prevent the parameter gradient from being swallowed by machine precision when compared to the massive $X_1$ and $X_2$ gradients.Log-Space Parameter Reparameterization: The utilization of log-space reparameterization ($\theta = \exp(\phi)$) for the 13 scalar parameters is a highly recommended practice. It strictly prevents negative physical values (e.g., negative mass or stiffness) and effectively normalizes the parameter space gradients, which is essential to complement the output space normalization.7. Synthesis and Concrete RecommendationsBased on the exhaustive review of system identification theory, multiple shooting optimal control frameworks, and statistical machine learning literature, the following concrete recommendations are provided to solve the normalization problem for the quasi-LPV state-space system parameter recovery.7.1 Rejection of Signal Variance MethodsOption A (Global Signal Sigma) must be unequivocally rejected. Standardizing by the global signal standard deviation conflates the amplitude of the experimental excitation with the reliability of the data. It will blind the optimizer to the $Y$-channel in $X$-only trajectories, preventing the accurate recovery of cross-coupling parameters and allowing the model to learn physically impossible dynamics.Option B (Per-Trajectory Sigma) must be unequivocally rejected. Dynamically changing the loss function scale per trajectory introduces heterogeneous, constantly shifting units into the Adam optimizer's mini-batches. This destroys the consistency of the momentum estimates, prevents the gradient from pointing toward the true global Maximum Likelihood estimate, and induces catastrophic parameter wandering.7.2 The Theoretically Optimal Approach: Inverse Noise Variance (MLE)The mathematically rigorous answer to the core problem is to normalize the squared errors by the Inverse Measurement Noise Variance.$$Loss = \sum_{batch} \left( \frac{(X_1 - \hat{X}_1)^2}{\sigma^2_{noise, X1}} + \frac{(X_2 - \hat{X}_2)^2}{\sigma^2_{noise, X2}} + \frac{(Y - \hat{Y})^2}{\sigma^2_{noise, Y}} \right)$$If the sensors measuring $X_1$, $X_2$, and $Y$ have known noise floors (obtainable from sensor datasheets or static, zero-excitation calibration data), these scalar values must form a fixed, global normalizer. This approach is theoretically optimal, directly aligns with the Fisher Information Matrix to achieve the Cramér-Rao lower bound, handles structurally constant signals flawlessly without risking division by zero, and provides the Minimum Variance Unbiased Estimator.7.3 The Pragmatic Approach: Global Initial RMSE (Modified Option C)If the precise measurement noise variance is unknown, or if structural model mismatch heavily dominates the sensor noise, the superior pragmatic approach is a variation of Option C, implemented specifically as a Global Initial RMSE Normalizer.Implementation Steps:Prior to training, execute a forward pass of the initial, detuned quasi-LPV model over the entire concatenated dataset encompassing all heterogeneous trajectories.Compute the global Root Mean Square Error for each individual channel: $RMSE_{init, X1}$, $RMSE_{init, X2}$, $RMSE_{init, Y}$.Utilize the squared inverse of these global values as fixed, constant weights in the MSE loss function throughout the entirety of the Adam training process.$$Loss = \sum_{batch} \left( \frac{(X_1 - \hat{X}_1)^2}{RMSE_{init, X1}^2} + \frac{(X_2 - \hat{X}_2)^2}{RMSE_{init, X2}^2} + \frac{(Y - \hat{Y})^2}{RMSE_{init, Y}^2} \right)$$Theoretical Justification for this Specific Setup:Gradient Consistency: Because the normalizers are fixed globally, the mini-batch gradients remain perfectly mathematically consistent, preserving the critical efficacy of the Adam optimizer's first and second momentum tracking mechanisms.Initial Gradient Balancing: At epoch 0, this normalization ensures that the loss contribution from each channel is approximately equal. The optimizer is thereby mathematically forced to care about recovering parameters that reduce the error in $Y$ just as intensely as parameters that reduce the error in $X_1$, completely circumventing amplitude domination.Handling Heterogeneous Constraints: During an $X$-only trajectory, the true $Y$ channel is constant. The initial model will predict some error in $Y$ (likely due to incorrect, detuned cross-coupling parameters). Because $RMSE_{init, Y}$ is a global constant derived from actual model error—not the local, zero-variance physical signal—the division by zero is safely avoided. Furthermore, the loss function strongly and correctly penalizes any dynamic prediction in $Y$ during this trajectory, forcing the cross-coupling physical parameters to their true values to maintain the constant output.7.4 Advanced Implementation: Iteratively Reweighted Least SquaresGiven the use of a continuous-time LPV system integrated with RK4 over short segments ($0.1–0.6$ s at $20$ kHz), the initial parameters may be severely detuned, causing the initial $RMSE$ to be heavily skewed by transient integration errors rather than structural physics.To maximize identifiability and parameter recovery accuracy, it is highly recommended to upgrade the Global Initial RMSE approach to an Iteratively Reweighted Least Squares (IRLS) methodology.IRLS Workflow:Train the model for a designated number of epochs using the Global Initial RMSE weights.Pause the training loop.Compute the new RMSE of the partially trained model across the entire concatenated dataset.Update the fixed normalizers in the loss function to these new squared inverse RMSE values.Crucially, reset the Adam optimizer's state (momentum and variance trackers) to prevent contamination from the old loss scale.Resume training.This iterative process systematically pushes the normalizers toward the true Maximum Likelihood noise covariance matrix, systematically eliminating bias and isolating the true 13 physical parameters governing the quasi-LPV system.
