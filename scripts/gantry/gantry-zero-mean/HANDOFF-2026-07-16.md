## The question this folder answers
From Jan's 2026-07-15 meeting: the trained ANN augmentation learns a non-zero-mean ("DC")
per-step correction; on the K=0 (X/Y) free-integrator axes that DC integrates into unbounded
free-run drift. Jan's Theme A hypothesis: maybe the with-MSD SYSTEM is genuinely non-zero-mean
(the absorber sits at an offset L0 = 0.10 m in +Y), so the ANN is correctly learning a real
constant. Goal: locate the origin of the DC — system/data (G-A), estimator assumptions (G-B),
or training dynamics (G-C).

## SETTLED: G-A (system side) is refuted at first order — the system is NOT meaningfully non-zero-mean
Three independent measurements, all point the same way:
- **Formula-level** (README V1 bullet): in `gantrySystemExtended.m` the offset L0 enters ONLY the
  mass matrix (inertia/coupling, multiplies accelerations) and the coordinate definition; there is
  NO constant force term (horizontal axis, no gravity, spring unpreloaded). So delta_a=0 is an
  exact equilibrium; zero-mean forcing → zero-mean response, except a tiny 2nd-order rectification
  through the nonlinear M(Y+L0+delta_a) (the sin²→½ effect). Vertical mounting WOULD create a real
  DC (gravity preload); ours is horizontal, so it does not.
- **v1b** (`v1b_q_mean_with_without_msd.py`, Python, closed-loop, 12 matched records): mean(with) −
  mean(without) consistent with ZERO on every channel (positions both frames, velocities, forces);
  max |dmean|/(2·SE) = 0.31. delta_a |mean|/std ~ 1e-4 (the rectification level).
- **v1d** (`v1d_openloop_same_input_msd.m`, MATLAB, OPEN-loop, SAME input, T1 + T8): the direct
  truth−baseline difference under identical input is ~1e-5 max. It carries a real but tiny slow
  DETERMINISTIC trend (~1e-8..1e-6 m/s; the 2nd-order rectification), NOT structureless noise —
  the traces are visibly structured (diff X rises then ramps down). But it is 3–4+ orders below the
  ANN's drift (X ~6e-4, Y ~2e-3 m/s), so it cannot be what the ANN learns.

**The climb-and-park in v1d position plots is NOT the MSD.** Both plants (with and without MSD)
park IDENTICALLY (red on green), and the truth plant parks against its OWN data (replaycheck).
It is a one-time transient from the reconstructed input `u_total` (generator rebuilds it via
`u_fb = lsim(Cfb, r−q)` + variable-step interpolation; ZOH replay leaves a ppm-level low-freq
error) integrated by the springless axis and stopped by damping (τ = m/c). Common to both plants →
cancels in the difference. **Park = one-time transient (bounded); only a persistent force ramps
forever, which only the trained ANN does.** This is the cleanest one-figure message for Jan.
